# Project State

## Research branch

**Spatially Varying Test-Time ISP / Image Enhancement**

## Core scientific question

Can a vision system adapt a compact spatial image-processing state per test image, without test labels or clean/normal-light targets, so that unknown and spatially heterogeneous degradation is corrected by a reference-free test-time optimization field?

## Current deployable state

**T014 Sobolev Region2 TTT remains the broad fresh-qualified Ours-Core.** It uses the frozen nuisance readout + clean-abstention gate, source-supervised Sobolev restoration energy, hard Region2 EV+gamma adaptation, projected label-free updates, and minimum predicted-energy checkpoint selection.

On LOL-v2 Real development data, the official 100-pair test remains sealed. The accepted fixed-validation deployable base is **T026-A: `11.1208764 dB / 0.3737918 RGB-SSIM`**. T026-B showed that extending the same trajectory from 40 to 80 steps adds only `+0.1210491 dB / +0.0042526`, so the 40-step base remains fixed.

**T036-A common gain is the strongest fresh-qualified deployable action expansion so far.** On its deterministic reference-unused 100-pair training-development cohort it improves exact T026-A by `+0.9392571 dB / +0.0083560 RGB-SSIM` mean, but remains unsafe per image. It is a mechanism result, not the final deployable Ours.

## Optimization-field diagnosis

- **T028-A:** exact EV+gamma reference-only reachability `17.4599918 / 0.4317158`, proving substantial headroom beyond the learned path.
- **T029-A:** learned-field direction is strong early and collapses late: step-10 median cosine `0.7266` with `97%` positive-dot versus selected-state median cosine `-0.2785` with `24%` positive-dot.
- **T031/T032:** source-support distance predicts invalidity moderately well, but the direct global trust-radius controller fails.
- **T039-A:** on all `7,346` accepted canonical T014 source states and gains `{0.75,1.00,1.25}`, legacy alignment is `93.3545%` positive-dot / `0.955998` median cosine and later common-gain alignment is `85.2274% / 0.802533`; the frozen energy can therefore generalize to at least one later action tangent on source.
- **T041/T042:** late real legacy/feature-state extrapolation is a major local reliability failure; substituting fixed step-10 legacy coordinates restores strong directional alignment.
- **T043/T044:** directional validity does not equal absolute image quality, and raw late excursion is not a useful target-free risk score.
- **T058-AF:** the exact T054 local-detail tangent fails the preregistered frozen-energy source-readiness gate on all `7,346` canonical T014 source states: `4,959/7,244 = 68.4567%` positive-dot and `0.230516` median cosine, versus required `>=75%` and `>=0.50`. The result is a source-only diagnostic with immutable learned gradients frozen before clean-source reference gradients were opened. The frozen T014 field is therefore **not ready** for direct T054-detail integration. Descriptively, homogeneous-dark states are especially weak (`51.6782%`, median cosine `0.0209763`), while homogeneous-bright is stronger (`82.7819%`, `0.456648`); these subgroups do not alter the global verdict.
- **T059-BF:** matched dual-tangent source fitting is feasible with the unchanged 28-D T014 `EnergyHead` and one fixed `1:1:1` value/legacy/detail recipe. After exactly one seed-7 CPU 100-epoch fit on all `7,346` canonical source states, detail alignment reaches `98.7990%` positive-dot / `0.626633` median cosine while legacy remains `99.2826% / 0.966527`; value Huber is `0.0722323`, inside the preregistered `0.0765085` ceiling. This resolves the **in-source capacity** question positively but does not establish cross-image generalization or deployability because the same source-image banks were used for fitting and evaluation.
- **T059-C2:** the corrected fixed unique-image-held-out test is negative. One fresh fixed fit used `64` source images / `5,886` rows and evaluated only `16` unseen source images / `1,460` rows with zero image overlap. Held-out detail positive-dot is `0.845031` (passes `>=0.75`) but median cosine is `0.479706` (fails `>=0.50`); legacy remains `0.950694 / 0.938040` (both pass), while value Huber rises to `0.193253` (fails the `<=0.0765085` ceiling). The checkpoint was persisted before held-out supervision was opened. Thus the fixed T059-B recipe **does not establish image-held-out source generalization** and remains non-deployable; no real-domain detail rollout is authorized.
- **T059-D:** the frozen C2 held-out bank-relative audit rejects a pure additive-offset explanation. Subtracting each bank's deterministic `state_index==0` anchor reduces aggregate standardized value Huber from `0.1932531` to `0.1030146`, but this still exceeds the same `0.0765085` ceiling. Typical within-bank ordering is nevertheless strong: defined-bank Spearman median is `0.961288` and argmin-regret median is `0`; the failure has a severe tail, including bank 300 with relative Huber `4.565146`, Spearman `-0.6452`, and regret `6.04693`. The original global detail median cosine remains `0.479706`, so T059-C2 stays negative. This establishes that cross-bank energy zero is partly nuisance, but the remaining failure also contains genuine within-bank geometry/scale errors rather than only an additive calibration shift.
- **T059-E:** directly training the value term in bank-relative form also fails the fixed nested source-development transfer test. With the already-observed C2 outer holdout completely excluded, one fixed fit used `48` inner-train images / `4,357` rows and evaluated `16` inner-held images / `1,529` rows. Inner-held relative Huber is `0.221076` (fails `<=0.0765085`), detail positive-dot is `0.868874` (passes) but median cosine is `0.491553` (fails `>=0.50`), while legacy remains `0.957011 / 0.905764` (both pass). Inner-train relative Huber is `0.056903`. Median held-out Spearman is `0.935652` and median argmin regret is `0`, so ordering remains much stronger than scalar amplitude calibration. The checkpoint was persisted before inner-held supervision opened; outer-supervision reads and all target/test leakage counters are zero. Therefore **bank-relative amplitude regression is not a sufficient generalization fix**, and this line remains non-deployable.
- **T059-F2:** the frozen strict-positive scale audit rejects the remaining simple calibration explanation. On the same `1,529` T059-E inner-held rows / `80` banks, the preregistered least-squares positive-scale decomposition yields a strict-positive-limit Huber of `0.2147133`, still far above the fixed `0.0765085` ceiling. The partition is `60` positive-scale banks, exactly three nonconstant positive-boundary banks `230/280/305`, and `17` degenerate singletons. Ordering/argmin are preserved from the original prediction under the mathematically correct `a→0+` semantics. Thus the T059-E value failure is **not explained by bankwise positive-scale miscalibration after offset removal**; genuine within-bank shape/order error remains in the tail. This is a source-only diagnostic and does not reverse T059-E or authorize rollout.
- **T059-G:** the fixed cross-image 1-NN support audit separates detail-direction support from scalar transfer. On the `4,357` inner-train rows, leave-one-image-out 1-NN passes all fixed gates: relative Huber `0.064456`, detail positive-dot `0.946449`, and detail median cosine `0.597402`. On the same `1,529` T059-E inner-held rows, detail direction still passes (`0.913245 / 0.528418`) but the bank-relative scalar Huber fails sharply at `0.231723`. The complete held-out neighbor map was frozen from the 28-D standardized features before held-out supervision opened, all `5,886` neighbor IDs/ties were independently replayed, the excluded C2 outer supervision remained unopened, and leakage counters are zero. Thus the 28-D representation contains useful cross-image local information for the desired detail direction, while scalar geometry does not transfer under fixed 1-NN. The preregistered classification is that T059-E is **consistent with an inner-held feature-support shift**, but this is not causal proof: the held-out nearest-distance distribution moves only modestly, so simple support-density shift versus conditional scalar aliasing remains unresolved.

The deployable bottleneck remains two-sided: the renderer/action family must be expressive enough, and the learned target-free optimization field must remain valid over unseen images and the states/directions it visits. T054–T057 establish that local detail/noise control is the strongest missing renderer capability found so far. T058-AF shows the frozen T014 field does not transfer strongly enough to that 64-D detail tangent; T059-BF shows the same 28-D head can fit legacy and detail tangents jointly in-source; T059-C2 then shows that this fixed fit does not satisfy the preregistered unseen-image gate; T059-D shows additive bank centering cannot rescue the held-out scalar-value failure; T059-E shows that learning a state-0-relative amplitude objective directly still does not transfer; T059-F2 shows the remaining scalar failure is not reducible to a bankwise positive multiplicative scale; and T059-G shows that the same fixed 28-D space supports held-out detail direction under a nonparametric cross-image readout while scalar transfer still fails. The next justified question is whether that scalar failure is explained by **larger feature-space support distance itself** or by conditional scalar target mismatch / aliasing at comparable distance.

The capacity diagnosis is now sharper. T054 establishes **local detail/noise control** as a high-value missing capability, while T055 closes simple one-scale budget rescue and T056/T057 show only small broad-positive returns from a coarser frequency band or chroma/luminance detail decoupling. T058-AF then shows that the current frozen T014 energy does not supply a sufficiently aligned gradient for the T054 direction. T059-BF demonstrates that this incompatibility is trainable rather than an architectural impossibility, but T059-C2 shows the fixed matched recipe does not transfer strongly enough across unseen source images: detail direction narrowly misses its median-cosine gate and scalar value calibration degrades sharply. T059-D and T059-F2 rule out simple additive-offset and positive-scale-only explanations, while T059-E shows that directly optimizing bank-relative amplitude still overfits the development images and again narrowly misses detail-cosine transfer. T059-G then shows that the fixed 28-D representation is not devoid of transferable local detail information: cross-image 1-NN clears both held-out detail-direction gates, but still fails scalar relative-Huber badly. Renderer micro-extension and real-domain rollout therefore remain paused while we distinguish simple support-distance shift from scalar feature aliasing before committing to support augmentation versus representation redesign.

## Information-boundary rules

- Test-time adaptation and checkpoint selection must never consume test labels, clean/normal-light targets, reference gradients/Jacobians, oracle values, PSNR/SSIM, degradation masks/gain maps, condition IDs, annotations, or semantic image IDs.
- Validation/test outputs and decisions must be finalized and persisted before references or evaluation metrics are attached, except in explicitly isolated non-deployable reference diagnostics.
- Reference diagnostics may motivate only global research choices; no per-image oracle quantity may enter deployable inference.
- Source-training clean/reference targets may be used only for source-supervised training or isolated source-domain diagnostics; they are never admissible test-time inputs.
- External baselines admitted to the main comparison must be target-free at inference.
- Fresh/final benchmark sets must remain isolated from model/hyperparameter selection. **The official LOL-v2 Real test remains untouched through T059-G.**
- Fresh/test runs must fail closed on source/checkpoint/cohort/provenance mismatches.
